# Contributing to FRONTEND-

This repository is currently a placeholder for frontend learning work.

## Before adding a project

- Choose and document the framework and supported Node.js version.
- Add a package manifest and lockfile using one package manager.
- Keep application code and reusable components organized.
- Add exact development, build, lint, and preview commands to the README.
- Do not commit `node_modules`, build output, local secrets, or personal environment files.

## Quality expectations

- Check responsive behavior at mobile and desktop widths.
- Use semantic HTML, accessible labels, keyboard navigation, and readable contrast.
- Handle loading, empty, and error states.
- Test navigation and forms before describing a feature as complete.

## Pull requests

Explain the purpose, include screenshots for visual changes, list commands run, and document any known limitations.
